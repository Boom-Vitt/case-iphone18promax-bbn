# BBN — The Cognac Edit

Premium iPhone 18 Pro Max case concept film, authored in Blender on 2026-09-14. A tobacco-cognac leather shell, saddle stitching, raised camera surround, separate lenses, side controls, and bottom openings appear in a charcoal/champagne studio.

## Deliverables

- `iphone18-pro-max-premium.mp4` — 16 seconds, 1920×1080, 24 fps, H.264/AAC, original stereo ambient score; progressively downloadable MP4.
- `iphone18-pro-max-premium.blend` — editable 32-part case assembly, procedural leather material, studio lighting, four animated cameras, typography and a keyed 360° rotation. Active scene: `BBN_Premium_Film`.
- `hero.png` — Full HD still from the final shot.
- `film-contact-sheet.png` — one encoded-video sample per second, in viewing order.
- `ambient-score.wav` — original synthesized score generated by `finish_video.py`; no third-party music or voice recording.
- `build_premium.py` — scene authoring source, executed through official Blender MCP.
- `render_frames.py` — resumable Blender render and framing checks.
- `finish_video.py` — score generation, MP4 encoding and technical validation.
- `render-validation.json`, `video-validation.json` — validation reports generated only after successful rendering/encoding.
- `prompts.md` — user prompt, interpreted creative brief and source references.

The original `../cognac-turntable.blend` remains intact. This is an advertising model with approximate geometry, not manufacturing CAD or a verified fit specification. The existing store GLB belongs to the earlier asset set and is not the refined material in this film.

## Film

| Time | Shot |
| --- | --- |
| 0–4 s | Slow silhouette reveal with the case and collection title |
| 4–8 s | Moving close-up of the camera surround, lenses and leather grain |
| 8–12 s | Full 360° rotation showing the front, sides and rear |
| 12–16 s | Final product shot and collection title |

The camera-detail shot deliberately crops the body. All other shots keep the complete case within the frame. Blender renders use EEVEE with 128 temporal samples, ray tracing and three shadow rays; the included scene also retains Cycles settings for optional still rendering. The finished video adds short opening/closing fades and a restrained original ambient score.

## Render again

Use Blender 5.2.1, Python 3, FFmpeg with libx264/AAC, and FFprobe. Run from the repository root; substitute your Blender executable path if needed.

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background blender/advertisement/premium/iphone18-pro-max-premium.blend --python-exit-code 1 --python blender/advertisement/premium/render_frames.py
python3 blender/advertisement/premium/finish_video.py
```

The frame script resumes valid existing PNGs in `frames/`. When changing the scene, use an empty frame directory or move the old one aside so old frames are not reused. Raw frames, previews and render logs are ignored by Git; final deliverables and source stay in this directory.

To recreate the scene from the earlier source asset, open `../cognac-turntable.blend` and execute `build_premium.py` through Blender MCP or Blender's Python editor. The script creates a new scene and refuses to overwrite an existing `BBN_Premium_Film`. Its output directory is `premium/` beside the source blend.

## Provenance and validation

Base model: `../build_scene.py` and `../cognac-turntable.blend`, authored earlier in this repository through official Blender MCP. Phone appearance reference: [Apple launch imagery](https://www.apple.com/newsroom/2026/09/apple-debuts-iphone-18-pro-and-iphone-18-pro-max/); local reference notes are in `../../../output/leather-cases/references/sources.md`. The leather case is an original BBN design concept; reference photographs are not used as video footage.

`render_frames.py` checks 384 camera selections and all 288 complete-product frame bounds. `finish_video.py` checks dimensions, 384 distinct source frames, output frame count, duration, stereo audio, clipping in the source score and a complete FFmpeg decode. Visual review of rendered shots is recorded separately in `review.md`.
